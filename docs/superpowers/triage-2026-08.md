## Systemic finding: the Zap/craic-competitions family (fixed, `593dc5d`)

Skip-reason distribution across 9 never-scraped woo ops (385 draws scraped, 0 inserted):
294× missing draw_date, 82× missing total_entries. Cause: the **Zap Competitions**
(craic-competitions) WP plugin renders cap + countdown client-side from a public
admin-ajax call (`action=zap_competition_ajax_refresh&ids[]=<id>` →
`tickets_max`, `tickets_days_remaining`). Static pages + Store API carry neither field.

Fix: `lib/zap.mjs` (detect / parse / merge, fixture-tested) + batched ajax call in
`wooOperator`. First probe: **⚡ filled cap/date for 161 draws** (storm 59, capital-carp 54,
drift 48); batch went 0 → 24 insertable drafts. Remaining skips in the family are policy,
not parsing: dateless AUTO-DRAW comps (drawn on sellout — ajax returns no days_remaining)
and small entry pools (`only N entries — non-standard draw`, businessGate).
