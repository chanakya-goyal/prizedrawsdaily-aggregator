# Operation 1000 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hold 1000+ live draws on PrizeDrawsDaily by unblocking the daily scrape (CI test gate), reviving silent operators, and building a keyless operator-discovery engine with human approval.

**Architecture:** The existing aggregator (Bun, deterministic, no-LLM) stays as-is; we fix its CI gate, deepen render extraction, and add two sibling modules: `manager/tripwire.mjs` (failure alarm) and `discovery/` (source scan → probe → trust screen → approval queue → one-command onboarding). Everything network-dependent is dependency-injected so the CI test gate stays offline-deterministic.

**Tech Stack:** Bun (not Node), bun:test, cheerio, Playwright (render feeder only), Supabase PostgREST, GitHub Actions (FlareSolverr service container already wired), `gh` CLI.

## Global Constraints

- **Keyless philosophy:** no paid APIs in CI. SerpApi (user's key) runs locally only, never in a workflow.
- **No LLM in the scraper or discovery pipeline** — deterministic extraction only (the cowork routine is the only AI, unchanged).
- **Publishing policy unchanged:** scraped draws land as `status='draft'`; cowork QA publishes. No auto-publish.
- **New operators reach the site DB only via human approval** (`discovery/approve.mjs`), inserted with `review_status: null` so the site renders them as unverified (no fabricated review content — `DrawCard.tsx` only badges `review_status === "published"`).
- **CI test gate = `bun test test/` only.** Every test added to `test/` must pass offline with no network, no Chromium, no ffmpeg.
- **Bun idioms:** `Bun.file`, `bun test`, `bun <file>`; no npm/node tooling (repo CLAUDE.md).
- **Supabase:** URL `https://kkuuwksgyypicnblwubs.supabase.co`; service key in repo-root `.env` (`SUPABASE_SERVICE_ROLE_KEY`); PostgREST caps selects at 1000 rows — always page (`sbGetAll` pattern from `run.mjs:46`).
- The daily Action runs `main` — fixes only take effect after push to `origin/main`.
- Do NOT touch the uncommitted carousel changes (`carousel/build.mjs`, `carousel/config.json`, `carousel/render.mjs`) — stage files explicitly, never `git add -A`.

- [ ] **Step 3: Implement `manager/tripwire.mjs`**

```js
// Tripwire: exits 1 (and writes tripwire.md) when the daily pipeline is silently broken —
// the scrape step didn't succeed, or live inventory fell under the floor. The Aug 2026
// outage (carousel tests skipping the scrape for 10+ days) is exactly what this catches.
// Usage (CI): SCRAPE_OUTCOME=${{ steps.scrape.outcome }} bun manager/tripwire.mjs
const SB = process.env.SUPABASE_URL || "https://kkuuwksgyypicnblwubs.supabase.co";
const KEY = process.env.SUPABASE_SERVICE_ROLE_KEY || "";

export function evaluateTripwire({ activeCount, floor, scrapeOutcome }) {
  const reasons = [];
  if (scrapeOutcome !== "success") reasons.push(`scrape step outcome was '${scrapeOutcome}' (expected 'success')`);
  if (activeCount != null && activeCount < floor) reasons.push(`live inventory ${activeCount} is under the floor of ${floor}`);
  return { tripped: reasons.length > 0, reasons };
}

const isMain = import.meta.path === Bun.main;
if (isMain) {
  const floor = Number(process.env.TRIPWIRE_FLOOR || 350);
  const scrapeOutcome = process.env.SCRAPE_OUTCOME || "unknown";
  let activeCount = null;
  try {
    const r = await fetch(`${SB}/rest/v1/draws?select=id&status=eq.active`, {
      headers: { apikey: KEY, Authorization: `Bearer ${KEY}`, Prefer: "count=exact", Range: "0-0" },
    });
    activeCount = Number((r.headers.get("content-range") || "/0").split("/")[1]);
  } catch { /* count stays null — outcome check still applies */ }
  const { tripped, reasons } = evaluateTripwire({ activeCount, floor, scrapeOutcome });
  const body = [
    `## 🔴 Aggregator tripwire — ${new Date().toISOString().slice(0, 10)}`,
    "", ...reasons.map((x) => `- ${x}`), "",
    `Active draws: **${activeCount ?? "unknown"}** (floor ${floor}) · scrape outcome: **${scrapeOutcome}**`,
    "", "Check the run's coverage-report step summary for the per-operator picture.",
  ].join("\n");
  await Bun.write("tripwire.md", body);
  if (tripped) { console.error(reasons.join("; ")); process.exit(1); }
  console.log(`tripwire ok — active ${activeCount}, scrape ${scrapeOutcome}`);
}
```

- Produces: `trustScreen(domain: string, { fetchImpl = fetch }) → Promise<{ domainAgeDays: number|null, companyNumber: string|null, hasTerms: boolean, trustpilotUrl: string|null, trustpilotScore: number|null, socials: string[] }>`
  - Domain age: `GET https://rdap.org/domain/<domain>` → earliest `events[].eventDate` where `eventAction === "registration"`.
  - Company number: homepage text match `/company\s*(?:no|number|registration)[.:\s#]*(\d{8})/i` or `/registered .{0,60}?(\d{8})/i`.
  - `hasTerms`: any homepage `<a href>` matching `/terms|t&cs|terms-and-conditions/i`.
  - Trustpilot: `GET https://uk.trustpilot.com/review/<domain>` → if 200, parse `"ratingValue"` from embedded JSON-LD; 404 → both null.
  - Socials: homepage hrefs matching `facebook.com|instagram.com|tiktok.com` (deduped hostnames+paths, max 5).
  - Every sub-check is best-effort: failures yield nulls/false, never throw.

`run.mjs` main flow (behind the same `import.meta.path === Bun.main` guard as tripwire):
1. `const found = (await Promise.all(sources.map(s => s.candidates({}).catch(() => [])))).flat()`
2. Normalize + dedupe by `norm(domain)` against itself and `knownOperatorSet()`.

### Task 12: Weekly discovery workflow

**Files:**
- Create: `.github/workflows/discovery.yml`

**Interfaces:**
- Consumes: `discovery/run.mjs` (keyless sources only — no SerpApi key in CI by design).
- Produces: weekly QUEUE.md in the step summary + run artifact. No auto-commit, no DB writes.

- [ ] **Step 1: Write the workflow**

```yaml
name: Weekly operator discovery (keyless — approval queue only)

on:
  schedule:
    - cron: "0 6 * * 1" # Mondays 06:00 UTC
  workflow_dispatch: {}

jobs:
  discover:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    permissions:
      contents: read
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2
        with:
          bun-version: latest
      - run: bun install
      - name: Gate (scraper tests)
        run: bun run test:scraper
      - name: Run discovery (seeds + crosslink + competitor sources; serpapi skips without a key)
        run: bun discovery/run.mjs
      - name: Publish queue to summary
        if: always()
        run: cat discovery/QUEUE.md >> "$GITHUB_STEP_SUMMARY" 2>/dev/null || echo "no queue produced" >> "$GITHUB_STEP_SUMMARY"
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: discovery-queue
          path: |
            discovery/QUEUE.md
            discovery/queue.json
          if-no-files-found: ignore
```
